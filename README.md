# CareLink

CareLink is an Android application designed to assist caregivers in monitoring and supporting users through reminders, emergency SOS alerts, evidence capture, and AI-powered assistance.

## Features

- 👤 Caregiver dashboard
- 🔔 Reminder management
- 🚨 Emergency SOS alerts
- 📸 Evidence capture
- 🗣️ Gesture-based controls
- 🤖 AI-powered chatbot assistance
- 📞 Caregiver communication
- 🔐 User authentication
- ☁️ Firebase integration

## Technologies Used

- Java
- Android Studio
- XML
- Firebase
- Cloudinary
- Claude API
